CommandCenter API

HTTP API for listing agents, creating chat sessions, sending messages, streaming responses, searching past sessions, and reusing files already stored in CommandCenter’s chat library.

Public Base URL: https://your-domain.example/commandcenter/api/v1

Local Base URL: http://127.0.0.1:3001/api/v1 (optional localhost-only listener for same-machine apps)

Auth: public listener uses Authorization: Bearer YOUR_COMMANDCENTER_API_KEY; the optional localhost-only listener can be used without a bearer token.

Recommended setup: keep the public /api/v1 listener keyed, and enable the localhost-only listener for trusted local programs like desktop companions, automations, or your own super app.
OpenAPI JSON Back to CommandCenter
AgentsList and search available agents
SessionsCreate, reuse, inspect, and search conversation threads
StreamingSSE lifecycle events for accepted/thinking/response/done
AttachmentsPass reusable chat-library file IDs into API turns
Voice AudioReturn agent speech using the voice assigned in CommandCenter

Agent Discovery + Super App Integration

GET /agents is the best first call for any companion app, desktop shell, mobile wrapper, or super app.

CommandCenter merges agents from two possible sources into one roster:

  • OpenClaw — loaded from ~/.openclaw/openclaw.json → agents.list
  • Hermes — loaded from hermes profile list plus hermes profile show <profile>

Every returned agent includes a source field so your app can tell whether it came from OpenClaw or Hermes without doing silly name-guessing.

Recommended app flow:

  1. Call GET /agents
  2. Use primaryAgentId as the default target
  3. Let the user pick an agent by id / label
  4. Create a session with POST /sessions
  5. Send turns through POST /sessions/:id/messages or POST /chat
# local same-machine example
curl http://127.0.0.1:3001/api/v1/agents

# useful fields to keep in your app model
# - id
# - label
# - name
# - source
# - bridge
# - workspace
# - model
# - aliases
# - primaryAgentId (top-level response)

External Client Contract

If you are building a local device client, desktop wrapper, companion app, or another app-layer bridge, these are the most useful parts of CommandCenter’s API surface.

  • GET /agents — roster discovery + primaryAgentId
  • POST /sessions — create a stable chat session
  • GET /sessions and GET /sessions/:id/messages — recent history and transcript loading
  • POST /sessions/:id/messages — normal chat turns
  • POST /sessions/:id/messages/stream — SSE event flow for live UI/state updates
  • POST /chat — convenience wrapper if you want less session bookkeeping
  • /voice + /voice/options — optional voice resolution and assignment
  • /files endpoints — reusable attachment/link workflows

Stable fields worth building against:

  • Agent: id, label, name, source, bridge, workspace, model, aliases
  • Session: id, agent, title, createdAt, updatedAt, messageCount, lastMessagePreview, metadata
  • Message: id, role, text, timestamp, meta
  • Top-level roster field: primaryAgentId

Presentation-only fields: treat color, voice, and visual as UI metadata, not your routing contract.

Endpoints

List available agents.

GET/agents/search?q=anby

Search agents by id, label, or name.

POST/sessions

Create a new chat session for an agent.

GET/files

List reusable files and links available for fileIds.

POST/files/upload

Upload files directly into the API file library.

POST/files/link

Save a reusable link directly into the API file library.

GET/files/:id/download

Download uploaded files or redirect to saved links.

GET/sessions

List recent sessions.

GET/sessions/:id

Get session metadata.

GET/sessions/:id/messages

Get session transcript.

POST/sessions/:id/messages

Send a non-streaming message to an existing session. Supports fileIds.

POST/sessions/:id/messages/stream

Send a message and receive SSE lifecycle events. Supports fileIds.

POST/chat

Convenience endpoint that auto-creates or resumes a session. Supports fileIds.

GET/sessions/search?q=nicole

Search sessions by transcript content.

Attachments

The API now supports attachments by passing fileIds that refer to files or links stored in CommandCenter’s reusable file library.

You can now manage that file library directly through /api/v1 too:

  • GET /commandcenter/api/v1/files
  • POST /commandcenter/api/v1/files/upload
  • POST /commandcenter/api/v1/files/link

When fileIds are supplied, the API injects attachment context into the prompt and stores attachment references in the session transcript metadata.

# upload a file to the v1 API file library
curl -X POST https://your-domain.example/commandcenter/api/v1/files/upload \
  -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  -F "files=@./spec.pdf"

# save a reusable link
curl -X POST https://your-domain.example/commandcenter/api/v1/files/link \
  -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/doc","name":"Example Doc","notes":"reference"}'

# download a stored file
curl -L -X GET https://your-domain.example/commandcenter/api/v1/files/YOUR_FILE_ID/download \
  -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  -o downloaded-file.bin

# use returned fileIds in a chat request
{
  "message": "Summarize this doc for me.",
  "fileIds": ["f3d2...", "9ab1..."]
}

Voice + Audio

You can ask chat endpoints to return audio too by sending "audio": true. The API will synthesize the reply with the selected agent’s current CommandCenter voice settings.

You can also update the voice assigned to an agent through the v1 API.

  • GET /commandcenter/api/v1/voice?agent=anby — inspect current voice settings and resolve the voice for an agent
  • GET /commandcenter/api/v1/voice/options?provider=elevenlabs — list selectable voices, or ?provider=fish&q=yuna to search Fish voices
  • POST /commandcenter/api/v1/voice — update the provider and/or assign a voice to an agent
  • POST /commandcenter/api/v1/chat with "audio": true — receive text plus base64 audio in the same response
  • POST /commandcenter/api/v1/sessions/:id/messages/stream with "audio": true — receive an extra SSE audio event
# inspect the resolved voice for an agent
curl "https://your-domain.example/commandcenter/api/v1/voice?agent=anby"   -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY"

# assign a new voice to an agent
curl -X POST https://your-domain.example/commandcenter/api/v1/voice   -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY"   -H "Content-Type: application/json"   -d '{"provider":"fish","agent":"anby","voiceId":"YOUR_FISH_OR_ELEVENLABS_VOICE_ID"}'

# request text + audio from the convenience chat endpoint
curl -X POST https://your-domain.example/commandcenter/api/v1/chat   -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY"   -H "Content-Type: application/json"   -d '{"agent":"anby","message":"Say hi and introduce yourself.","audio":true}'

Streaming

Streaming uses Server-Sent Events (SSE).

V1 streams lifecycle events such as accepted, thinking, response, and done. It is not guaranteed to be token-by-token model streaming.

For external clients, this is the best endpoint when you want to forward live state into your own WebSocket/event layer without polling like a goblin.

event: accepted
data: {"sessionId":"ccs_...","messageId":"msg_...","agent":"anby","files":[]}

event: thinking
data: {"agent":"anby","status":"Processing..."}

event: response
data: {"agent":"anby","text":"New Eridu. That's where I'm from."}

event: audio
data: {"contentType":"audio/mpeg","base64":"...","provider":"fish","voiceId":"..."}

event: done
data: {"ok":true,"sessionId":"ccs_...","responseId":"msg_..."}

History + Auth Notes

History: use GET /sessions for recent conversations, GET /sessions/:id for metadata, and GET /sessions/:id/messages for the transcript itself.

Local auth: when the localhost-only listener is enabled, same-machine clients can call it without a bearer token.

Public auth: the public/network listener requires Authorization: Bearer YOUR_COMMANDCENTER_API_KEY.

If both are available on the same device, prefer the local listener for trusted local clients.

Unified Python CLI Examples

Standard API CLI (no Fairy live calls)

This script covers the normal CommandCenter API flow: list agents, optionally tweak voices, choose agent or roleplay mode, start or reuse a session, and chat over the auth-protected /api/v1 surface.

# Standard library imports
import base64
import json
import os
import subprocess
import sys
import tempfile
from pathlib import Path
from typing import Optional

import requests

try:
    import httpx
except ImportError:
    httpx = None

try:
    import sounddevice as sd
    import numpy as np
except ImportError:
    sd = None
    np = None

BASE = os.environ.get("COMMANDCENTER_BASE", "https://your-domain.example/commandcenter/api/v1")
API_KEY = os.environ.get("COMMANDCENTER_API_KEY", "YOUR_COMMANDCENTER_API_KEY")
API_KEY = API_KEY.removeprefix("Bearer ").strip()


def headers(extra=None):
    h = {"Authorization": f"Bearer {API_KEY}"}
    if extra:
        h.update(extra)
    return h


def get_json(path, params=None):
    r = requests.get(f"{BASE}{path}", headers=headers(), params=params, timeout=60)
    r.raise_for_status()
    return r.json()


def post_json(path, payload):
    r = requests.post(
        f"{BASE}{path}",
        headers=headers({"Content-Type": "application/json"}),
        json=payload,
        timeout=180,
    )
    r.raise_for_status()
    return r.json()


def list_agents():
    return get_json("/agents").get("agents", [])


def choose_agent():
    agents = list_agents()
    if not agents:
        raise RuntimeError("No agents returned by the API.")
    print("\nAvailable agents:")
    for idx, agent in enumerate(agents, 1):
        display = agent.get("name") or agent.get("label") or agent.get("id")
        print(f"  {idx}. {display} [{agent.get('id')}]")
    while True:
        raw = input("\nChoose an agent by number: ").strip()
        if raw.isdigit() and 1 <= int(raw) <= len(agents):
            return agents[int(raw) - 1]
        print("Invalid choice. Try again.")


def ask_yes_no(prompt, default=False):
    suffix = " [Y/n]: " if default else " [y/N]: "
    raw = input(prompt + suffix).strip().lower()
    if not raw:
        return default
    return raw in {"y", "yes"}


def choose_streaming():
    if httpx is None:
        print("\nhttpx is not installed, so streaming is unavailable. Using non-streaming mode.")
        return False
    return ask_yes_no("Enable streaming?", default=True)


def choose_audio():
    return ask_yes_no("Enable audio replies and auto-play them?", default=False)


def search_sessions(agent_id: Optional[str] = None):
    query = input("Enter search text for the session: ").strip()
    if not query:
        print("No search text entered.")
        return None
    params = {"q": query, "limit": 10}
    if agent_id:
        params["agent"] = agent_id
    results = get_json("/sessions/search", params=params).get("results", [])
    if not results:
        print("No matching sessions found.")
        return None
    print("\nMatching sessions:")
    for idx, item in enumerate(results, 1):
        title = item.get("title") or "(untitled session)"
        snippet = item.get("snippet") or ""
        print(f"  {idx}. {title} [{item.get('sessionId')}]\n     {snippet}")
    while True:
        raw = input("Choose a session by number, or press Enter to cancel: ").strip()
        if not raw:
            return None
        if raw.isdigit() and 1 <= int(raw) <= len(results):
            return results[int(raw) - 1]["sessionId"]
        print("Invalid choice. Try again.")


def choose_mode():
    raw = input("Mode (agent/roleplay) [agent]: ").strip().lower()
    return "roleplay" if raw in {"roleplay", "rp"} else "agent"


def choose_session(agent_id: str, mode: str):
    if not ask_yes_no("Use an existing session?", default=False):
        title = input("Optional title for the new session (press Enter to skip): ").strip()
        session = post_json("/sessions", {"agent": agent_id, "title": title, "mode": mode})["session"]
        print(f"Created new session: {session['id']} ({mode})")
        return session["id"]
    if ask_yes_no("Do you already know the session ID?", default=True):
        session_id = input("Enter the session ID: ").strip()
        if session_id:
            return session_id
        print("No session ID entered. Falling back to search.")
    found = search_sessions(agent_id=agent_id)
    if found:
        print(f"Using session: {found}")
        return found
    print("No existing session selected. Creating a new one instead.")
    session = post_json("/sessions", {"agent": agent_id, "mode": mode})["session"]
    print(f"Created new session: {session['id']} ({mode})")
    return session["id"]


def get_resolved_voice(agent_id: str):
    return get_json("/voice", params={"agent": agent_id}).get("resolved") or {}


def list_voice_options(provider: str, query: str = ""):
    params = {"provider": provider}
    if provider == "fish":
        params["q"] = query
    return get_json("/voice/options", params=params).get("items", [])


def pick_voice_from_menu(provider: str):
    query = ""
    if provider == "fish":
        query = input("Enter a Fish voice search query (for example yuna): ").strip()
        if not query:
            print("Fish voice search needs a query. Skipping voice update.")
            return None
    items = list_voice_options(provider, query=query)
    if not items:
        print("No voices returned for that provider/query.")
        return None
    print("\nAvailable voices:")
    for idx, item in enumerate(items, 1):
        voice_id = item.get("voice_id") or item.get("id") or item.get("ref_id") or item.get("modelId") or item.get("voiceId") or item.get("_id") or ""
        label = item.get("name") or item.get("title") or item.get("label") or voice_id
        print(f"  {idx}. {label} [{voice_id}]")
    while True:
        raw = input("Choose a voice by number, or press Enter to cancel: ").strip()
        if not raw:
            return None
        if raw.isdigit() and 1 <= int(raw) <= len(items):
            item = items[int(raw) - 1]
            voice_id = item.get("voice_id") or item.get("id") or item.get("ref_id") or item.get("modelId") or item.get("voiceId") or item.get("_id") or ""
            label = item.get("name") or item.get("title") or item.get("label") or voice_id
            return {"voiceId": voice_id, "label": label}
        print("Invalid choice. Try again.")


def playable_suffix_from_content_type(content_type: str) -> str:
    normalized = (content_type or "").lower()
    if "wav" in normalized:
        return ".wav"
    if "mpeg" in normalized or "mp3" in normalized:
        return ".mp3"
    if "ogg" in normalized or "opus" in normalized:
        return ".opus"
    return ".bin"


def safe_filename_fragment(value: str) -> str:
    cleaned = "".join(ch if ch.isalnum() or ch in {"-", "_"} else "-" for ch in (value or "").lower())
    cleaned = "-".join(part for part in cleaned.split("-") if part)
    return cleaned or "agent"


def play_audio_blob(audio: dict, agent_name: str):
    if not audio or not audio.get("base64"):
        return
    content_type = audio.get("contentType", "audio/mpeg")
    suffix = playable_suffix_from_content_type(content_type)
    safe_agent = safe_filename_fragment(agent_name)
    path = Path(tempfile.gettempdir()) / f"commandcenter-{safe_agent}{suffix}"
    path.write_bytes(base64.b64decode(audio["base64"]))
    print(f"[audio] saved {path}")
    try:
        if sys.platform.startswith("win"):
            os.startfile(str(path))
        elif sys.platform == "darwin":
            subprocess.Popen(["open", str(path)])
        else:
            subprocess.Popen(["xdg-open", str(path)])
        print(f"[audio] playing {agent_name} voice reply")
    except Exception as err:
        print(f"[audio] Could not auto-play audio: {err}")


def send_non_stream(session_id: str, message: str, agent_name: str, want_audio: bool):
    data = post_json(f"/sessions/{session_id}/messages", {"message": message, "audio": want_audio})
    print(f"\n{agent_name}: {data.get('response', {}).get('text', '')}\n")
    if want_audio:
        play_audio_blob(data.get("audio"), agent_name)


def send_stream(session_id: str, message: str, agent_name: str, want_audio: bool):
    if httpx is None:
        print("httpx is not installed. Falling back to non-streaming mode.")
        return send_non_stream(session_id, message, agent_name, want_audio)
    audio_payload = None
    print()
    with httpx.stream(
        "POST",
        f"{BASE}/sessions/{session_id}/messages/stream",
        headers=headers({"Content-Type": "application/json", "Accept": "text/event-stream"}),
        json={"message": message, "audio": want_audio},
        timeout=180,
    ) as r:
        r.raise_for_status()
        event_type = None
        for line in r.iter_lines():
            if not line:
                event_type = None
                continue
            if line.startswith("event: "):
                event_type = line[7:]
                continue
            if line.startswith("data: "):
                payload = line[6:]
                try:
                    data = json.loads(payload)
                except json.JSONDecodeError:
                    data = {"raw": payload}
                if event_type == "thinking":
                    print(f"[thinking] {data.get('status', 'Processing...')}")
                elif event_type == "response":
                    print(f"{agent_name}: {data.get('text', '')}\n")
                elif event_type == "audio":
                    audio_payload = data
                    print(f"[audio] received {data.get('contentType', 'audio')} from {data.get('provider', 'tts')}")
                elif event_type == "error":
                    print(f"[error] {data}")
                elif event_type == "accepted":
                    print(f"[accepted] session={data.get('sessionId')}")
                elif event_type == "done":
                    print(f"[done] responseId={data.get('responseId')}\n")
    if want_audio:
        play_audio_blob(audio_payload, agent_name)


def update_agent_voice(agent_id: str):
    resolved = get_resolved_voice(agent_id)
    print(f"Current voice for {agent_id}: provider={resolved.get('provider', 'unknown')} voiceId={resolved.get('voiceId', '(none)')}")
    if not ask_yes_no("Do you want to update this agent's voice before chatting?", default=False):
        return
    provider_raw = input("Voice provider (elevenlabs/fish, press Enter to keep current): ").strip().lower()
    provider = provider_raw if provider_raw in {"elevenlabs", "fish"} else (resolved.get("provider") or "elevenlabs")
    picked = pick_voice_from_menu(provider)
    if not picked:
        print("No new voice selected. Keeping the current voice.")
        return
    result = post_json("/voice", {"provider": provider, "agent": agent_id, "voiceId": picked["voiceId"]})
    updated = result.get("resolved") or {}
    print(f"Updated voice for {agent_id}: provider={updated.get('provider')} voiceId={updated.get('voiceId')} label={picked['label']}")


def chat_loop(session_id: str, streaming: bool, agent_name: str, want_audio: bool):
    print("\nChat ready. Type /exit to quit, /session to print the current session ID.")
    while True:
        message = input("You: ").strip()
        if not message:
            continue
        if message.lower() in {"/exit", "exit", "quit"}:
            print("Goodbye.")
            return
        if message.lower() == "/session":
            print(f"Current session: {session_id}")
            continue
        if streaming:
            send_stream(session_id, message, agent_name, want_audio)
        else:
            send_non_stream(session_id, message, agent_name, want_audio)


def main():
    print("CommandCenter API CLI (standard)")
    print(f"Base URL: {BASE}")
    if API_KEY == "YOUR_COMMANDCENTER_API_KEY":
        print("Warning: replace YOUR_COMMANDCENTER_API_KEY or set COMMANDCENTER_API_KEY in your environment.")
    agent = choose_agent()
    mode = choose_mode()
    streaming = choose_streaming()
    want_audio = choose_audio()
    update_agent_voice(agent["id"])
    session_id = choose_session(agent["id"], mode)
    agent_name = agent.get("name") or agent.get("label") or agent.get("id")
    print(f"\nAgent: {agent_name}")
    print(f"Mode: {mode}")
    print(f"Streaming: {'enabled' if streaming else 'disabled'}")
    print(f"Audio: {'enabled' if want_audio else 'disabled'}")
    print(f"Session: {session_id}")
    chat_loop(session_id, streaming, agent_name, want_audio)


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print("\nInterrupted.")
        sys.exit(130)

Fairy CLI (text-mode live calls)

This separate script actually starts a Fairy live call, sends text turns through /api/call/*, waits for replies, includes default agent fallback, better timeout/error messaging, scoped Fairy memory lookups, and save-to-file session logging via /save.

import json
import os
import sys
import time
from pathlib import Path

import requests

BASE_V1 = os.environ.get("COMMANDCENTER_BASE", "https://your-domain.example/commandcenter/api/v1")
API_KEY = os.environ.get("COMMANDCENTER_API_KEY", "YOUR_COMMANDCENTER_API_KEY")
API_KEY = API_KEY.removeprefix("Bearer ").strip()
BASE_ROOT = BASE_V1[:-len('/api/v1')] if BASE_V1.endswith('/api/v1') else BASE_V1.rstrip('/')
LOG_DIR = Path(os.environ.get("COMMANDCENTER_FAIRY_LOG_DIR", "."))


def headers(extra=None):
    h = {"Authorization": f"Bearer {API_KEY}"}
    if extra:
        h.update(extra)
    return h


def get_json(url, params=None):
    r = requests.get(url, headers=headers(), params=params, timeout=60)
    r.raise_for_status()
    return r.json()


def post_json(url, payload):
    r = requests.post(url, headers=headers({"Content-Type": "application/json"}), json=payload, timeout=180)
    r.raise_for_status()
    return r.json()


def list_agents():
    return get_json(f"{BASE_V1}/agents").get("agents", [])


def choose_agent():
    agents = list_agents()
    if not agents:
        raise RuntimeError("No agents returned by the API.")
    primary = next((agent for agent in agents if agent.get("id") in {"main", "orchestrator"}), agents[0])
    print("\nAvailable agents for Fairy handoff context:")
    for idx, agent in enumerate(agents, 1):
        display = agent.get("name") or agent.get("label") or agent.get("id")
        marker = " (default)" if agent.get("id") == primary.get("id") else ""
        print(f"  {idx}. {display} [{agent.get('id')}]" + marker)
    while True:
        raw = input("\nChoose an agent by number (or press Enter for default): ").strip()
        if not raw:
            chosen = primary.get("id")
            print(f"Using default agent: {chosen}")
            return chosen
        if raw.isdigit() and 1 <= int(raw) <= len(agents):
            return agents[int(raw) - 1]["id"]
        print("Invalid choice. Try again.")


def fairy_config():
    return get_json(f"{BASE_V1}/fairy/config")


def fairy_settings():
    return get_json(f"{BASE_V1}/fairy/settings")


def update_fairy_settings(patch):
    return post_json(f"{BASE_V1}/fairy/settings", patch)


def start_fairy_call(agent=None):

    return post_json(f"{BASE_V1}/fairy/calls/start", payload)


def get_fairy_session(session_id):

def send_fairy_text(session_id, text):
    return post_json(f"{BASE_V1}/fairy/calls/{session_id}/text", {"text": text})

def send_fairy_audio_chunk(session_id, pcm16_base64, mime_type="audio/pcm;rate=16000"):
    return post_json(f"{BASE_V1}/fairy/calls/{session_id}/audio", {"pcm16Base64": pcm16_base64, "mimeType": mime_type})


def capture_mic_pcm16_base64(seconds=4, sample_rate=16000):
    if sd is None or np is None:
        raise RuntimeError("Mic capture requires sounddevice + numpy (pip install sounddevice numpy)")
    seconds = max(1, int(seconds))
    print(f"[mic] recording {seconds}s at {sample_rate} Hz...")
    audio = sd.rec(int(seconds * sample_rate), samplerate=sample_rate, channels=1, dtype="int16")
    sd.wait()
    pcm_bytes = np.asarray(audio, dtype=np.int16).tobytes()
    return base64.b64encode(pcm_bytes).decode("ascii")


def send_fairy_screen_frame(session_id, jpeg_base64, mime_type="image/jpeg"):
    return post_json(f"{BASE_V1}/fairy/calls/{session_id}/screen", {"jpegBase64": jpeg_base64, "mimeType": mime_type})


def send_fairy_camera_frame(session_id, jpeg_base64, mime_type="image/jpeg"):
    return post_json(f"{BASE_V1}/fairy/calls/{session_id}/camera", {"jpegBase64": jpeg_base64, "mimeType": mime_type})


def mark_playback_finished(session_id):
    return post_json(f"{BASE_ROOT}/api/call/{session_id}/event", {"type": "assistant.playback_finished"})


def end_fairy_call(session_id):
    return post_json(f"{BASE_V1}/fairy/calls/{session_id}/end", {})


def wait_until_ready(session_id, timeout=30):
    started = time.time()
    last_state = None
    while time.time() - started < timeout:
        session = get_fairy_session(session_id).get("session", {})
        state = session.get("state")
        if state != last_state:
            print(f"[fairy] state -> {state}")
            last_state = state
        if state == "ready":
            return session
        if state == "error":
            raise RuntimeError(f"Fairy session entered error state: {json.dumps(session, indent=2)}")
        time.sleep(0.75)
    raise TimeoutError(f"Timed out waiting for Fairy session to become ready after {timeout}s.")


def wait_for_reply(session_id, previous_text="", timeout=60):
    started = time.time()
    last_seen = previous_text or ""
    last_state = None
    while time.time() - started < timeout:
        session = get_fairy_session(session_id).get("session", {})
        current = (session.get("lastAssistantText") or "").strip()
        state = session.get("state")
        if state != last_state:
            print(f"[fairy] state -> {state}")
            last_state = state
        if current and current != last_seen and state in {"speaking", "ready", "task_running"}:
            return session
        time.sleep(0.9)
    raise TimeoutError(
        f"Timed out waiting for Fairy reply after {timeout}s. "
        f"Last known state was {last_state or 'unknown'}. Try /status to inspect the session."
    )


def print_fairy_status(session_id):
    session = get_fairy_session(session_id).get("session", {})
    print(json.dumps(session, indent=2))


def save_session_log(session_id):
    LOG_DIR.mkdir(parents=True, exist_ok=True)
    session = get_fairy_session(session_id).get("session", {})
    path = LOG_DIR / f"fairy-session-{session_id}.json"
    path.write_text(json.dumps(session, indent=2) + "\n", encoding="utf-8")
    print(f"[saved] {path}")


def print_fairy_memory(query="", scope="all"):
    params = {}
    if query:
        params["q"] = query
    if scope and scope != "all":
        params["scope"] = scope
    print(json.dumps(get_json(f"{BASE_V1}/fairy/memory", params=params or None), indent=2))


def fairy_chat_loop(session_id, agent_id):
    auto_mic = False
    auto_mic_seconds = 4
    print("\nFairy API call mode ready (text + audio + video frame uplink).")
    print("Commands: /status, /ready, /end, /save, /audio-file <pcm16.b64.txt>, /mic <seconds>, /auto-mic on|off [<seconds>], /screen-file <jpeg.b64.txt>, /camera-file <jpeg.b64.txt>, /fairy-config, /fairy-settings, /set-setting <key> <json-value>, /fairy-memory <query>, /fairy-memory-scope <scope> <query>, /fairy-sessions, /fairy-session <id>, /exit")
    while True:
        message = input("You → Fairy: ").strip()
        if not message and auto_mic:
            message = f"/mic {auto_mic_seconds}"
        if not message:
            continue
        if message.lower() in {"/exit", "exit", "quit"}:
            print("Leaving Fairy chat. Session is still live unless you used /end.")
            return
        if message.lower().startswith('/auto-mic '):
            parts = message.split()
            mode = parts[1].lower() if len(parts) >= 2 else "on"
            if mode in {"on", "start"}:
                auto_mic = True
                if len(parts) >= 3 and parts[2].isdigit():
                    auto_mic_seconds = max(1, int(parts[2]))
                print(f"Auto mic enabled ({auto_mic_seconds}s chunks). Press Enter to capture/send each turn.")
            else:
                auto_mic = False
                print("Auto mic disabled.")
            continue
        if message.lower() == "/status":
            print_fairy_status(session_id)
            continue
        if message.lower() == "/ready":
            data = mark_playback_finished(session_id)
            print(json.dumps(data, indent=2))
            continue
        if message.lower() == "/save":
            save_session_log(session_id)
            continue
        if message.lower().startswith('/audio-file '):
            path = message.split(' ', 1)[1].strip()
            pcm_b64 = Path(path).read_text(encoding="utf-8").strip()
            print(json.dumps(send_fairy_audio_chunk(session_id, pcm_b64), indent=2))
            continue
        if message.lower().startswith('/mic'):
            try:
                raw = message.split(' ', 1)[1].strip() if ' ' in message else "4"
                seconds = int(raw)
                before = get_fairy_session(session_id).get("session", {})
                previous_text = (before.get("lastAssistantText") or "").strip()
                pcm_b64 = capture_mic_pcm16_base64(seconds=seconds)
                send_fairy_audio_chunk(session_id, pcm_b64)
                reply_session = wait_for_reply(session_id, previous_text=previous_text)
                assistant = (reply_session.get("lastAssistantText") or "").strip()
                print(f"\nFairy: {assistant}\n")
                synthesize_and_play_fairy_text(assistant, agent_id=agent_id)
                if reply_session.get("state") == "speaking":
                    mark_playback_finished(session_id)
            except Exception as err:
                print(f"Mic uplink failed: {err}")
            continue
        if message.lower().startswith('/screen-file '):
            path = message.split(' ', 1)[1].strip()
            jpg_b64 = Path(path).read_text(encoding="utf-8").strip()
            print(json.dumps(send_fairy_screen_frame(session_id, jpg_b64), indent=2))
            continue
        if message.lower().startswith('/camera-file '):
            path = message.split(' ', 1)[1].strip()
            jpg_b64 = Path(path).read_text(encoding="utf-8").strip()
            print(json.dumps(send_fairy_camera_frame(session_id, jpg_b64), indent=2))
            continue
        if message.lower() == "/fairy-config":
            print(json.dumps(fairy_config(), indent=2))
            continue
        if message.lower() == "/fairy-settings":
            print(json.dumps(fairy_settings(), indent=2))
            continue
        if message.lower().startswith('/set-setting '):
            rest = message.split(' ', 1)[1].strip()
            key, _, raw_value = rest.partition(' ')
            if not key or not raw_value:
                print("Usage: /set-setting <key> <json-value>")
                continue
            try:
                value = json.loads(raw_value)
            except Exception:
                value = raw_value
            print(json.dumps(update_fairy_settings({key: value}), indent=2))
            continue
        if message.lower().startswith('/fairy-memory-scope '):
            rest = message.split(' ', 1)[1].strip()
            scope, _, query = rest.partition(' ')
            if not scope:
                print("Usage: /fairy-memory-scope <scope> <query>")
                continue
            print_fairy_memory(query=query.strip(), scope=scope.strip())
            continue
        if message.lower().startswith('/fairy-memory'):
            _, _, raw = message.partition(' ')
            print_fairy_memory(query=raw.strip(), scope='all')
            continue
        if message.lower() == '/fairy-sessions':
            print(json.dumps(get_json(f"{BASE_V1}/fairy/sessions"), indent=2))
            continue
        if message.lower().startswith('/fairy-session '):
            fairy_id = message.split(' ', 1)[1].strip()
            if not fairy_id:
                print("Usage: /fairy-session <id>")
                continue
            print(json.dumps(get_json(f"{BASE_V1}/fairy/sessions/{fairy_id}"), indent=2))
            continue
        if message.lower() == "/end":
            print(json.dumps(end_fairy_call(session_id), indent=2))
            return

        try:
            before = get_fairy_session(session_id).get("session", {})
            previous_text = (before.get("lastAssistantText") or "").strip()
            result = send_fairy_text(session_id, message)
            print(f"[accepted] route={result.get('route')} state={result.get('session', {}).get('state')}")
            reply_session = wait_for_reply(session_id, previous_text=previous_text)
            assistant = (reply_session.get("lastAssistantText") or "").strip()
            print(f"\nFairy: {assistant}\n")
            synthesize_and_play_fairy_text(assistant, agent_id=agent_id)
            if reply_session.get("state") == "speaking":
                mark_playback_finished(session_id)
        except requests.HTTPError as err:
            body = err.response.text if err.response is not None else str(err)
            print(f"[http-error] {body}")
        except TimeoutError as err:
            print(f"[timeout] {err}")
        except Exception as err:
            print(f"[error] {err}")


def main():
    print("CommandCenter Fairy CLI (text mode)")
    print(f"API base: {BASE_V1}")
    print(f"Call base: {BASE_ROOT}/api/call")
    print(f"Log dir: {LOG_DIR.resolve()}")
    if API_KEY == "YOUR_COMMANDCENTER_API_KEY":
        print("Warning: replace YOUR_COMMANDCENTER_API_KEY or set COMMANDCENTER_API_KEY in your environment.")

    cfg = fairy_config()
    print("\nFairy config summary:")
    print(json.dumps(cfg, indent=2))

    agent = choose_agent()
    started = start_fairy_call(agent=agent)
    session = started.get("session", {})
    session_id = session.get("id")
    if not session_id:
        raise RuntimeError(f"Did not receive Fairy session id: {json.dumps(started, indent=2)}")
    print(f"\nStarted Fairy call: {session_id}")
    wait_until_ready(session_id)
    print("Fairy session is ready.")
    fairy_chat_loop(session_id, agent)


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print("\nInterrupted.")
        sys.exit(130)

Fairy API Quickstart

1) Read Fairy config

curl -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  https://your-domain.example/commandcenter/api/v1/fairy/config

Use this first to confirm Fairy/Gemini live is configured, which voice is active, whether memory is enabled, and what persona name is currently set.

2) Inspect Fairy memory

curl -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  "https://your-domain.example/commandcenter/api/v1/fairy/memory?q=voice&scope=general"

Use this to search local Fairy memory entries. Example scopes in this API/docs set are general, ui, backend, and research.

3) List Fairy sessions

curl -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  https://your-domain.example/commandcenter/api/v1/fairy/sessions

Use this to inspect active/recent Fairy call sessions and grab a session id if you want to look at one specific live call record.

4) Inspect one Fairy session

curl -H "Authorization: Bearer YOUR_COMMANDCENTER_API_KEY" \
  https://your-domain.example/commandcenter/api/v1/fairy/sessions/<session-id>

Fairy session states documented in the OpenAPI spec are starting, ready, listening, thinking, speaking, task_running, ended, and error.

OpenAPI

A machine-readable OpenAPI spec is now available here:

/commandcenter/docs/openapi.json

You can use it with tooling that understands OpenAPI 3.1.

Fairy endpoints documented there include /fairy/config, /fairy/memory, /fairy/sessions, and /fairy/sessions/{id}.

The Fairy session state enum is documented as: starting, ready, listening, thinking, speaking, task_running, ended, error.

Example memory scopes used in the docs: general, ui, backend, research.

Example placeholder used in docs: YOUR_COMMANDCENTER_API_KEY

Error Format

{
  "ok": false,
  "error": "Session not found",
  "code": "SESSION_NOT_FOUND"
}
If you expose this API to the internet, set COMMANDCENTER_API_KEY. Otherwise you are leaving agent control routes open, which is a deeply unserious security choice.
