# OpenClaw Command Center is going open source

I’ve been building a weird little thing called OpenClaw Command Center, and I’m finally getting it ready to open source.

At a high level, it’s a self-hosted AI command center for OpenClaw and Hermes. But the real pitch is simpler than that: it turns your agent stack into something you can actually watch, talk to, and steer in real time.

Instead of another plain chat window, Command Center gives you a living pixel-art office with live agent presence, a terminal-style activity log, voice input and output, direct chat, companion visuals, and realtime Fairy Live sessions with mic, screen share, and camera input.

The part I like most is that it doesn’t just sit there looking pretty. It can reflect activity happening outside the UI too, which means it starts to feel less like a themed frontend and more like an actual status surface for your AI system.

A few things I think are especially fun:

- A living pixel-art AI ops dashboard instead of a static admin panel
- Unified OpenClaw + Hermes presence in one office and one roster
- Voice interaction with individual agents, wake mode, and spoken responses
- Fairy Live realtime calls with screen sharing and camera input
- Companion and Codex pet customization for agents
- Kiosk/PWA support for always-on displays and Raspberry Pi setups

This project is definitely opinionated. It likes character. It likes ambience. It likes making self-hosted AI feel alive instead of sterile. But under the style, the goal is practical: one place to monitor agents, interact with them, and understand what your local stack is doing.

I’m opening it up soon because I think it’ll get better faster once other people can poke at it, extend it, and probably bully my decisions in public.

Also, I want to be explicit about where this came from: this project builds on the original work by mayukh4. I forked from https://github.com/mayukh4/openclaw-command-center, and that original repo gave me the vision and made this whole project possible. A lot has changed since then, but the foundation and inspiration deserve real credit.

If you’re into self-hosted AI, agent dashboards, weird interfaces, voice-driven workflows, or making local systems feel more alive, keep an eye on this.
